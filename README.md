# 🏥 Patient Management System

A simple RESTful **Patient Management System** built using **FastAPI and Pydantic**.

The project demonstrates how to build APIs for creating, retrieving, and updating patient records while using Pydantic models for data validation and computed fields for automatic BMI and health-status calculation.

---

## 🚀 Features

- Create new patient records
- Retrieve all patient records
- Retrieve a specific patient using Patient ID
- Update existing patient information
- Pydantic-based request validation
- Automatic BMI calculation
- Automatic BMI-based health verdict
- JSON file-based data storage
- Proper HTTP status codes and error handling
- Interactive API documentation using FastAPI

---

## 🛠️ Tech Stack

- **Python**
- **FastAPI**
- **Pydantic**
- **JSON**
- **Uvicorn**
